# Cake Take Cake Boutique

A responsive React and Vite bakery website. Requires Node.js 20.19+ or 22.12+.

## Run locally
1. Open a terminal in this folder.
2. Run `npm install`.
3. Run `npm run dev` and open the local URL printed in the terminal.

Run `npm run build` to create the production site in `dist`, and `npm run preview` to preview that build.

## Editing
Update business details and reference prices in `src/data.js`. The images are illustrative placeholders; replace them with approved bakery photographs. Prices should be confirmed with the bakery.

## Deployment
For Vercel or Netlify, import this folder, use `npm run build` as the build command, and `dist` as the output directory.

## Enquiries
This frontend-only site prepares WhatsApp enquiries. Submitting a form does not place or confirm an order. Reference images are not uploaded or stored: attach them in WhatsApp. Fonts and illustrative photographs require internet access.
